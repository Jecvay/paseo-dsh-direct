# docs — 文档索引

本目录收录 paseo-dsh-pi 各子系统的细节文档。入口规则与红线见仓库根 `AGENTS.md`。

**本目录只写当前事实**：直接描述现在生效的机制，不写「以前如何、后来改成如何」。变更经过查 git log；仓外事件记 `.agents/ops-log.md`；决定的理由在 `.agents/notes/`。这条规则的存在是因为 docs 是给人和别的 agent 读的说明书——混进变更历史，读的人就不知道现在到底是什么。

**写作五条**（写完自查一遍）：

- 一个事实只在一处展开，其他地方链接过去——同一规则写两遍，改一处必漏另一处。
- 不写状态标注：「已实现！」「计划中：」会腐烂，结构自己说话。
- 不留推导过程：得出结论的推理路径删掉，留结论；「为什么」链接到 `.agents/notes/`。
- 处处加粗等于没有加粗，强调只留给改变行为的那一句。
- 不用比喻描述技术事实：写机制名、文件名、行为本身——比喻不可检索，也要求读者先解码再理解。

- 服务端架构（Daemon 侧 Provider 实现与 DSH 通信）：`server-architecture.md`
- 客户端架构（App 侧呈现与配置）：`client-architecture.md`
- 插件规范与设计参考（官方规则、优秀插件借鉴与外部链接）：`plugin-guide.md`
- 决定与理由（打算做 / 已做完 / 决定不做 / 已过时）：`../.agents/notes/`；规则见 `../.agents/notes/README.md`
- 仓外事件记录（git 项目按需建）：`../.agents/ops-log.md`（若存在）；svn/无版本控制项目的全量事件史：`../.agents/CHANGELOG.md`
